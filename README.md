# Projeto-Extensao-V-Engenharia-de-Software
EcoDescarte: especificação e modelagem de um sistema para o descarte correto de lixo eletrônico. Conecta cidadãos a pontos de coleta, com busca, orientações e agendamento de entregas. Projeto de Extensão V de Engenharia de Software (UVA), alinhado à ODS 12.
